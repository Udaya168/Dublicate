# Veytrix AI - AI Video Editing Suite

An advanced, browser-based AI video editing web application built with React, Vite, TypeScript, and Tailwind CSS.

Developed & Maintained by [venkyk23](https://github.com/venkyk23).

---

## 🚀 Key Features

### 🎬 Professional Timeline & Editing Suite
- **Split Clip at Playhead**: Split active video or audio clips precisely at the current playhead position (`Ctrl+B`).
- **Trim Start & Trim End**: Instantly cut clip start or end duration to playhead position with quick toolbar actions.
- **Freeze Frame Snapshot**: Capture video frames at playhead position into a 3.0-second frozen snapshot clip inserted seamlessly into the timeline.
- **Reverse Playback**: Play video clips in reverse order with visual badges and state persistence.
- **Lock / Unlock Clip**: Lock clips (`🔒`) to prevent accidental dragging, trimming, splitting, or deleting.
- **Multi-Track Timeline**: Support for multiple video, audio, text, overlay, and transition tracks.

### ⚡ Smooth Video Playback & Catch Protection
- Muted fallback and user-gesture autoplay handlers to guarantee zero video playback failures across all modern browsers.
- Metadata load safeguards for blob URLs and high-resolution video assets.

### 🎨 Filters, Transitions & AI Tools
- 50+ Pro Filters (Cinematic, Moody, Vintage, Cyberpunk, Black & White, Soft Skin, Neon, HDR).
- Dynamic canvas aspect ratios (16:9 YouTube, 9:16 Shorts/Reels/TikTok, 1:1 Instagram Square, Custom resolution).
- Auto-caption generator and customizable subtitle overlays.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/venkyk23/Dublicate.git

# Navigate to directory
cd Dublicate

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
